# Playbook — Knowledge Base للحملات الناجحة

مرجع ما أثبت نجاحه عندنا. كل حالة ناجحة تُوثّق هنا لتُستخدم كـ **Payload** جاهز
عند بناء حملات جديدة — أسرع في التنفيذ، أقل أخطاء، وتكرار لما نجح بدل البدء من الصفر.

**متى نضيف مدخلًا؟** عند أي Campaign / Ad Set / Ad يحقق نتائج جيدة، أو أي Setup
أو Strategy أو Best Practice تنجح معنا، أو أي اكتشاف أثناء مراجعة الحملات القديمة.

## القالب (انسخه لكل حالة ناجحة)

### [اسم الحالة] — [المنصة] — [التاريخ]

| البند | التفاصيل |
|---|---|
| **الحساب والمنصة** | اسم الحساب + الـ ID + المنصة |
| **المنتج والسوق** | المنتج + الدولة/السوق |
| **هدف الحملة** | Objective |
| **هيكلة الحملة** | عدد الـ Ad Sets وطريقة التقسيم، عدد الـ Ads داخل كل Ad Set |
| **الـ Audience** | Interests / LAL / Custom / Broad — بالتفصيل |
| **الـ Placements** | Automatic أو Manual + أي Placements تحديدًا |
| **Optimization Event** | Purchase / Lead / Add to Cart … |
| **الميزانية** | CBO أو ABO + المبلغ اليومي/الإجمالي |
| **Bidding Strategy** | Lowest Cost / Cost Cap / Bid Cap + القيمة |
| **الـ Creative** | النوع (VDO / IMG / Carousel) + الوصف + المدة |
| **الـ Copy** | Primary Text + Headline + CTA |
| **الـ Naming** | اسم الـ Campaign / Ad Set / Ad كاملًا |
| **الـ URL والـ UTMs** | الرابط كاملًا بكل المعاملات |
| **فترة التشغيل** | من — إلى |
| **النتائج** | Spend · Impressions · CTR · CPC · Conversions · CPA · ROAS |
| **وش اللي نجح** | العنصر المحدد اللي نعتقد إنه صنع الفرق |
| **ليش نجح** | التفسير |
| **وش نكرره أو نطوره** | التوصية للحملة الجاية |
